# امنیت و اعتبارسنجی

## نصب و Compose محلی
`node scripts/setup-local.cjs` بدون نیاز به npm، رمزهای تصادفی مستقل و فایل‌های محلی با مجوز 0600 می‌سازد. تنظیمات موجود PostgreSQL و MinIO حفظ می‌شود؛ Redis رمزدار می‌شود و URL سرور هماهنگ می‌گردد. پیش از تغییر فایل سرور، پشتیبان `.env.bak` ایجاد می‌شود. این اسکریپت برای production نیست.

رمزهای قدیمی volume با تغییر environment عوض نمی‌شوند. اگر قبلاً رمز نمونه استفاده شده، پس از پشتیبان‌گیری رمز PostgreSQL را با ALTER ROLE و رمز MinIO را از طریق مدیریت آن سرویس تغییر دهید؛ سپس تنظیمات را هماهنگ کنید. برای تغییر رمز volume را حذف نکنید.

پورت‌های PostgreSQL، Redis و MinIO تنها به 127.0.0.1 متصل‌اند. در Codespaces نیز این پورت‌ها باید Private بمانند. Compose برای توسعه است؛ production به TLS، firewall، مدیریت secrets، پشتیبان‌گیری و پایش جداگانه نیاز دارد.

تصویر نهایی Docker با کاربر غیر root و بدون source، tests و vendor اجرا می‌شود. CI نصب npm از checkout تازه، migration و schema، اجرای Compose با رمز تصادفی، رد Redis بدون رمز و ساخت bucket را بررسی می‌کند.

## آزمون، مجوز و حساب
تست API با احراز هویت و PostgreSQL/Redis واقعی نقش مهمان، دانشجوی غیرعضو، مدرس غیرمالک، مالک و مدیر را کنترل می‌کند. کلید پاسخ پیش از بسته‌شدن بازهٔ عمومی و زمان ارفاق، حتی پس از Submit زودهنگام، منتشر نمی‌شود؛ سپس نیز allowReview لازم است.

تست هم‌زمانی، Autosave/Submit، revision قدیمی، ذخیره پس از پایان و تکرار Submit را کنترل می‌کند. تست بازیابی رمز مصرف هم‌زمان ticket، رد استفادهٔ مجدد/توکن اشتباه و بی‌اعتبارشدن نشست قبلی را بررسی می‌کند. تست‌های موجود OTP و پرداخت نیز اجرا می‌شوند؛ درگاه پرداخت mock است.

## موبایل و عملکرد
سناریوی آزمون در عرض 390 پیکسل شامل reload، retry، axe و نبود اسکرول افقی است. ورود و میزکار مدیر نیز پوشش مرورگر دارند.

`node scripts/check-client-budget.cjs` پس از build سقف gzip فایل‌های JS اولیه را 200 KiB و CSS اولیه را 25 KiB نگه می‌دارد. این معیار حجم انتقال است و جای LCP/INP روی گوشی واقعی و شبکهٔ کند را نمی‌گیرد. تست بار، پرداخت واقعی و ممیزی تمام routeها هنوز نیازمند بررسی جداگانه‌اند.
