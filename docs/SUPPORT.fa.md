# راهنما و پشتیبانی داخلی

دکمهٔ «راهنما و پشتیبانی» در صفحهٔ اول و مسیر `/support` برای کاربران واردشده آماده است. مدیر با نقش SuperAdmin از همان مسیر صندوق همهٔ کاربران را می‌بیند، پاسخ می‌دهد و گفت‌وگو را می‌بندد. پیام جدید کاربر گفت‌وگو را دوباره باز می‌کند. پاسخ‌ها هر ۱۰ ثانیه هنگام باز بودن صفحه دریافت می‌شوند؛ حضور آنلاین یا پاسخ فوری ادعا نمی‌شود. برای جلوگیری از دسترسی دیگران، مهمان قبل از ارسال پیام انسانی باید وارد شود.

پیام‌ها در PostgreSQL ذخیره می‌شوند؛ ۱۰۰ پیام آخر نمایش داده می‌شود. پاسخ انسانی از پاسخ خودکار جداست؛ متن راهنما خودکار برای پشتیبان ارسال نمی‌شود. حذف حساب، گفت‌وگوی وابسته را حذف می‌کند. پیام‌ها متن ساده هستند؛ فایل پیوست و نمایش HTML فعال نیست. migration جدید را قبل از اجرای نسخهٔ جدید با `prisma migrate deploy` اعمال کنید. migrationهای قبلی تغییر نکرده‌اند.

## دستیار موقت رایگان

پیش‌فرض `ASSISTANT_PROVIDER=local` است. این یک راهنمای داخلی مبتنی بر موضوع‌های ثبت‌نام، ورود، OTP، پرداخت و آزمون است؛ مدل زبانی واقعی نیست و تماس خارجی/هزینهٔ API ندارد. راهنما در `server/src/lib/supportAssistant.ts` قابل ویرایش است. سؤال ناشناخته به پشتیبان ارجاع داده می‌شود.

## تعویض ارائه‌دهنده

فقط در env خصوصی سرور تنظیم کنید و برنامه را restart کنید؛ هیچ کلیدی در VITE، مرورگر، git یا پنل عمومی قرار نگیرد:

```dotenv
ASSISTANT_PROVIDER=openai-compatible
ASSISTANT_BASE_URL=https://api.openai.com/v1/
ASSISTANT_MODEL=MODEL_AVAILABLE_IN_YOUR_ACCOUNT
ASSISTANT_API_KEY=YOUR_PRIVATE_KEY
```

برای Claude مقدار provider را `anthropic`، آدرس را `https://api.anthropic.com/v1/` و مدل/کلید را مطابق حساب خود بگذارید. برای سرویس سازگار دیگر endpoint HTTPS با Chat Completions و `max_completion_tokens` لازم است؛ هر سرویس دلخواه الزاماً با این قرارداد سازگار نیست. adapter مستقل قابل گسترش است. شناسهٔ مدل عمداً ثابت نشده تا به نسخه یا شرکت خاص محدود نشوید. API مدل‌ها ممکن است پولی باشد؛ رایگان‌بودن ChatGPT یا Claude به معنی API رایگان نیست.

پیش از ارسال به مدل خارجی، کاربر رضایت می‌دهد. فقط سؤال فعلی و راهنمای عمومی ارسال می‌شود؛ تاریخچهٔ پشتیبانی، دادهٔ حساب، پاسخ آزمون و ابزار اجرایی به مدل داده نمی‌شود. متن خصوصی را داخل سؤال نفرستید. پاسخ مدل می‌تواند اشتباه باشد. شکست سرویس/timeout به راهنمای داخلی با برچسب صریح برمی‌گردد؛ اطلاعات خطای ارائه‌دهنده و کلید منتشر نمی‌شوند. هر پیام مستقل است و تاریخچهٔ گفت‌وگوی مدل فقط در حافظهٔ پنجره نمایش داده می‌شود.

محدودیت ۱۰ درخواست در دقیقه به‌ازای IP و ۶۰ درخواست در دقیقه به‌صورت کلی روی Redis اعمال می‌شود؛ برای مدل خارجی سقف سراسری روزانه نیز پیش‌فرض ۱۰۰ درخواست است و با ASSISTANT_DAILY_LIMIT تنظیم می‌شود؛ این محدودیت هزینهٔ ماهانه را تضمین نمی‌کند. پیش از فعال‌کردن API عمومی، سقف هزینهٔ سخت در حساب ارائه‌دهنده تعیین کنید. سقف خروجی ۶۰۰ توکن و timeout بیست ثانیه است. اتصال با حساب و مدل واقعی بعد از واردکردن تنظیمات باید بررسی شود؛ تست adapterها از پاسخ شبیه‌سازی‌شده استفاده می‌کند.
