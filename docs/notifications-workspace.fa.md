# میزکار و اعلان‌ها

- میزکار کاربر ارشد دسترسی سریع به درخواست‌ها، آزمون‌ها و گزارش‌ها دارد. تازه‌سازی دستی اطلاعات قبلی را نگه می‌دارد؛ در صورت شکست، وضعیت قدیمی مشخص می‌شود.
- ورود موفق با رمز، OTP یا گوگل یک اعلان شخصی با IP اتصال ثبت می‌کند. درخواست کد، ورود ناموفق، حساب منتظر تأیید و تمدید نشست اعلان ورود تولید نمی‌کنند.
- IP از `req.ip` سرور گرفته می‌شود. در محیط پشت پروکسی، تنظیم `TRUST_PROXY` باید با زیرساخت واقعی تطبیق داشته باشد؛ در غیر این صورت ممکن است IP پروکسی یا آدرس محلی نمایش داده شود. هدر ارسالی کاربر مستقیماً پذیرفته نمی‌شود.
- حذف اعلان از زنگوله فقط برای همان کاربر ثبت می‌شود و اعلان عمومی دیگران را پاک نمی‌کند. این حذف با تازه‌سازی صفحه نیز باقی می‌ماند. در صورت خطای حذف، اعلان در فهرست می‌ماند و امکان تلاش دوباره وجود دارد.

## دریافت نسخه در Codespace

در شاخه `codex/senior-workspace-polish`، پس از توقف سرور:

```bash
git pull --ff-only
npm exec -w server -- prisma migrate deploy
npm exec -w server -- prisma generate
npm run dev -w server
```

مهاجرت تنها ستون اختیاری `dismissedAt` را به `notification_reads` اضافه می‌کند. داده‌های قبلی حذف نمی‌شوند. پیش از اجرای کد جدید، مهاجرت باید روی دیتابیس همان محیط اجرا شود.
